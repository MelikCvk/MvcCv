## 📌 Proje Hakkında

Dinamik Cv Yönetim Sistemi, ASP.NET MVC ve Microsoft SQL Server kullanılarak geliştirilmiş dinamik bir kişisel portfolyo ve içerik yönetim sistemidir.

Sistem sayesinde kişisel bilgiler, deneyimler, eğitimler, projeler, sertifikalar, yetenekler, sosyal medya hesapları ve iletişim mesajları yönetim paneli üzerinden kolayca yönetilebilmektedir.

Statik Cv sitelerinin aksine tüm içerikler veritabanında tutulmakta ve yönetim paneli üzerinden dinamik olarak güncellenebilmektedir. 


Canlı site linki: Https://www.melikcvk.com

---

## 🎯 Projenin Amacı

Bu proje;

* ASP.NET MVC mimarisini uygulamak
* Entity Framework kullanarak veritabanı yönetimi gerçekleştirmek
* Repository Pattern mimarisini uygulamak
* Yönetim paneli geliştirmek
* CRUD işlemlerini yönetmek
* Dinamik içerik yönetimi oluşturmak

amacıyla geliştirilmiştir.

## ⚙️ Kurulum

### 1. Projeyi Klonlayın

```bash
git clone https://github.com/melik-cvk/dynamic-portfolio-management-system.git
```

### 2. Visual Studio ile Açın

Projeyi Visual Studio üzerinden açın.

### 3. Veritabanı Bağlantısını Güncelleyin

Web.config dosyası içerisindeki Connection String alanını kendi SQL Server bilgileriniz ile güncelleyin.

### 4. NuGet Paketlerini Yükleyin

```powershell
Update-Package -Reinstall
```

### 5. Projeyi Çalıştırın

```text
Ctrl + F5
```
